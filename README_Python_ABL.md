## Prerequisites

- Python 3 (Python 3.10 or later is recommended)
- A code editor such as Visual Studio Code
- Python extension in VS Code (optional, but useful)
- Git and a GitHub account for uploading the repository

No external Python packages are required. The programs use basic Python concepts covered in the syllabus.

## How to run a program

1. Download or clone this repository.
2. Open the folder in Visual Studio Code.
3. Open the `programs` folder.
4. Open any `.py` file.
5. Run the file using the Run button, or open the terminal and type:

   ```bash
   python3 programs/case_01_electricity_billing.py
   ```

6. Replace the example values in the program with your own test values if required.
